# Math operators - Python

```python
x = 10
y = 3

# Division
result = x / y # returns float 3.3333333333

result = int(x / y) # in case we need an int (с округлением)  3

# Деление без остатка
result = x // y # 3

# Остаток от деления
result = x / y # 1

## Возведение в степень
result = x ** y # возведет x в степень y (9^3)
```
